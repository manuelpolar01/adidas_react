# proyecto para aprender react

Este proyecto fue realizado para enseñar las bases de react con javascript 

![image] (/public/foto de proyecto.png)

### instalacion  ⚙
1. clone  el repositorio
2. haga el comando ` cd adidas-react` para moverse a la carpeta del proyecto
3. instale dependencias con el comando `npm install`
4. finalmente haga el comando `npm run dev` para levantar en el servidor local la app.

### version host 💻

si desea ver el proyecto online puede ingresar al siguiente link: [adidasreact]()

### librerias utilizadas 📄

- [React Boostrap]( https://react-bootstrap.netlify.app/): usada para el navbar y styling de la app
- [firebase](https://firebase.google.com/?hl=es-419): utilizada como base de datos
- [React router Dom](https://www.npmjs.com/package/react-router-dom) utilizada para navegacion ´por rutas de la app
